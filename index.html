concurrency

Race-proof matching

Two taps at the same moment still create exactly one job: SELECT … FOR UPDATE on the request plus a partial unique index on active jobs.

geo search

Expanding radius dispatch

ST_DWithin over a GIST index finds skill-matched, approved workers. If nobody responds, the radius grows 5 → 10 → 20 km on its own.

money integrity · razorpay

Automated, double-safe payments

Settlement runs in one locked transaction: balances can't go negative, coins are capped at 25%, and a job can't be settled twice. Razorpay webhooks (in progress) are signature-checked, and the unique gateway_txn_id makes a retried webhook harmless.

auth & security

Revocable sessions

15-minute JWTs, rotating hashed refresh tokens, PBKDF2 at 600k rounds, OTP attempt limits, and an admin kill-switch that logs a user out everywhere.

caching

Generation-based invalidation

The nearby-request lists are cached in Redis for 15 seconds. Any change bumps one counter, which invalidates every cached list at once.

trust

KYC review pipeline

Selfie, Aadhaar and PAN go to an admin queue with a 72h deadline (oldest first, overdue flagged). Only approved workers can see requests.
